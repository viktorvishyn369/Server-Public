Notes

  • Model weights are downloaded at runtime to reduce app size; the same licenses apply.
  • Some voices use models whose training-data provenance is documented upstream; per-model license metadata is maintained by each project's registry.
  • Non-commercial (e.g., CC-BY-NC) models are intentionally excluded from Blipp.
