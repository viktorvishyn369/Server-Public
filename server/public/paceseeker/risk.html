1. Software

PaceSeeker is alpha-quality, experimental software. Bugs and unexpected behavior may occur. There is no warranty or guarantee of correctness. SIM mode is available to test functionality without using real funds.

2. Market Conditions

  • Slippage: Actual execution prices may differ from quoted prices, especially for low-liquidity tokens or during volatile periods. PaceSeeker lets you set a slippage limit.
  • Liquidity: Thin pools can move against you between quote and execution.
  • MEV: All transactions on Solana are visible in the mempool before confirmation. This is how public blockchains work. PaceSeeker uses Jito bundles and slippage guards as mitigations.
  • Network: Stale blockhashes, dropped transactions, or slow confirmation may affect outcomes.

3. CEX Trading

  • CEX API keys with Trade permission can place real market orders.
  • If one leg of an arbitrage fails, your position becomes unhedged and PaceSeeker halts automatically.
  • Exchanges may rate-limit, reject orders, or experience outages mid-trade.
  • API keys with Withdraw permission can move funds. Use Trade-only keys if you do not need auto-rebalance.

API keys remain in device secure storage and are loaded into memory only for the duration of the signed API call. They are transmitted only to the exchange that issued them (via HTTPS/TLS). PaceSeeker has no backend server and no telemetry. Even if network traffic is intercepted, only HMAC signatures are visible.

4. Smart Contracts

DEX trades route through third-party smart contracts (Jupiter, Raydium, Orca, Meteora, etc.). PaceSeeker does not audit these contracts. Jupiter is the industry-standard router used by millions of wallets.

5. Session Wallet

The session wallet is a temporary keypair stored locally on your device in encrypted secure storage. It auto-expires after 24 hours of inactivity. Keep only the amount you intend to trade in the session wallet.

6. Device Security

PaceSeeker implements security measures: biometric gatekeeping, screenshot blocking, root detection, and a background security monitor. You are responsible for maintaining your device’s physical and digital security: use a lock screen PIN/biometric, do not install apps from unknown sources, and keep your operating system updated.

7. Third-Party Dependencies

PaceSeeker relies on third-party infrastructure that StealthLynk does not control:

  • Solana network: Congestion, validator issues, or protocol upgrades may affect transaction confirmation.
  • Jupiter Aggregator: Routing algorithm changes or API downtime may affect quote accuracy.
  • Jito Block Engine: Bundle rejection or engine downtime may prevent transaction inclusion.
  • Centralized exchanges: API outages, rate limits, or policy changes may affect trading.
  • RPC providers: Stale data or provider downtime may affect the bot’s view of the chain.

StealthLynk does not operate these services and is not liable for their failures or changes.
