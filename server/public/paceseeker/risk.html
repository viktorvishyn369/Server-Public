PaceSeeker — Self-Custody Trading Tool

Last Updated: August 29, 2026

PaceSeeker is automated trading software built with multiple layers of protection. SIM mode is available to observe behavior without using real funds.

1. Software

PaceSeeker is actively developed software. Like any software that interacts with live markets, behavior may vary. SIM mode is available to test functionality without using real funds.

2. Market Conditions

  • Slippage: Actual execution prices may differ from quoted prices, especially for low-liquidity tokens or during volatile periods. PaceSeeker lets you set a slippage limit.
  • Liquidity: Thin pools can move between quote and execution.
  • Network: Stale blockhashes, dropped transactions, or slow confirmation may affect outcomes.

3. CEX Trading

  • CEX API keys with Trade permission can place real market orders.
  • If one leg of an arbitrage fails, your position becomes unhedged and PaceSeeker pauses automatically.
  • Exchanges may rate-limit, reject orders, or experience outages mid-trade.
  • API keys with Withdraw permission can move funds. Use Trade-only keys if you do not need auto-rebalance.

API keys remain in device secure storage and are loaded into memory only for the duration of the signed API call. They are transmitted only to the exchange that issued them (via HTTPS/TLS). PaceSeeker has no telemetry and does not track your trading activity. Server interactions are limited to: (1) remote configuration fetched on startup (RPC URLs, Jupiter keys, feature flags — verified via Ed25519 signature or SHA-256 hash), and (2) a lightweight endpoint that receives the invite code when you redeem it to unlock LIVE mode — used for counting redemptions.

3.1 DCA Bot Trading

  • The DCA bot accumulates positions by buying at intervals based on AI-driven multi-timeframe signals. It may buy during downtrends if signals indicate a reversal.
  • Stop-loss is configured as a percentage below average entry price. It is not a guaranteed execution price — slippage, network congestion, or stale quotes may result in worse-than-expected fill prices.
  • Safety orders scale buy amounts when price deviates from the last buy, increasing exposure. This can amplify losses in sustained downtrends.
  • Take profit sells are executed via Jupiter swaps. Thin liquidity or rapid price movement may cause the sell to miss the target price.
  • The bot runs as a foreground service and continues trading while the app is in the background. You are responsible for monitoring the bot's activity and available USDC balance.
  • If the RPC endpoint is rate-limited or down, the bot cannot fetch market data or execute trades, potentially missing buy or sell opportunities.
  • DCA position state (average entry, total spent, trade markers) is stored locally on your device. If you uninstall the app or clear data, this state is lost and the bot cannot resume the previous position.

4. Smart Contracts and Token Safety

DEX trades route through industry-standard smart contracts (Jupiter, Raydium, Orca, Meteora, etc.) that are widely used. PaceSeeker validates every transaction before signing through its transaction safety layer, which checks instructions for unexpected operations.

The default token list is sourced from Jupiter's verified directory and filtered by liquidity and trading activity. Tokens you add manually via Token Scanner are your explicit choice. Always verify the mint address and liquidity of any token you add.

5. Session Wallet

The session wallet is a keypair stored locally on your device in encrypted secure storage. Generated sessions expire after 24 hours from creation; imported private keys and hardware wallet sessions persist until you revoke them.

6. Device Security

PaceSeeker implements security measures: biometric gatekeeping, screenshot blocking, root detection, and a background security monitor. Keep your device secure with a lock screen PIN or biometric, and keep your operating system updated.

7. Third-Party Dependencies

PaceSeeker relies on third-party infrastructure:

  • Solana network: Congestion, validator issues, or protocol upgrades may affect transaction confirmation.
  • Jupiter Aggregator: Routing changes or API downtime may affect quote accuracy.
  • Jito Block Engine: Bundle rejection or engine downtime may prevent transaction inclusion.
  • Centralized exchanges: API outages, rate limits, or policy changes may affect trading.
  • RPC providers: Stale data or provider downtime may affect the bot's view of the chain.

StealthLynk does not operate these services.

8. No Control

StealthLynk has no technical ability to shut down, disable, or revoke your access to PaceSeeker. The app runs entirely on your device with no licensing mechanism or kill switch. Once installed, PaceSeeker continues to function independently of StealthLynk.
