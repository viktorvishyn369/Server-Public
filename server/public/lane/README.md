# Lane — On-Device Voice Companion

<img src="../images/logo_lane.png" alt="Lane" width="120">

**Lane** is a local-first voice companion for Android — a voice assistant that runs entirely on your phone.

- **On-device AI**: local language model (Qwen via llama.cpp), offline Whisper speech recognition, and Kokoro/Piper voices — speech recognition, reasoning, and speech synthesis all happen on the device
- **Private by default**: conversations and memory never leave your phone; no analytics, no tracking
- **Optional cloud**: bring-your-own-key models (OpenAI, Anthropic, OpenRouter, Gemini, Groq, Together, Mistral) — strictly opt-in
- **Voice tools**: weather, web search, opening apps, alarms, dialing, emergency numbers, assistant settings
- **Solana**: optional MWA wallet connection and avatar cNFT publishing — always behind explicit confirmation

## Subscription

- **Price**: $1.75 USD/month launch price (regular $3.99) — paid in SOL, USDC, or SKR, no auto-renew
- **Trial**: one-time 7-day free trial per device; every entitlement carries a 3-day grace tail
- **Stacking**: purchases and earned free weeks start where the current term ends — remaining trial days are never lost
- **Free weekly option**: a verified weekly promo post grants 7 days on every app linked at claim time
- **Ecosystem**: a Lane subscription unlocks PaceSeeker and a 100 GB PhotoLynk plan on the same StealthLynk account — and any paid StealthLynk plan unlocks Lane. Apps link automatically by proving the same Solana wallet
